الخصوصية بالتصميم

أموالك شأنك وحدك.

صمم SpendCue بحيث لا يجمع المطور سجلاتك المالية الشخصية أو يبيعها أو يؤجرها أو يتتبعها.

لا حاجة إلى حساب

لا تسجيل لدى المطور ولا بيانات دخول لحساب بنكي.

بلا إعلانات أو تتبع

لا أدوات إعلانات ولا تتبع إعلاني عبر التطبيقات.
